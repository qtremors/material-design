# Privacy Policy for Material Design

**Last Updated:** 2026-08-30

Material Design is an educational reference project built with a local-first Android application. This policy explains how the application and project website handle information.

## 1. No App Data Collection

The Material Design Android app does not collect, store remotely, sell, or transmit personal data, usage statistics, crash reports, or telemetry.

## 2. Offline Android Application

The Android app does not declare the `android.permission.INTERNET` permission. Its catalog is bundled with the application, so browsing references, searching, viewing demos, and changing settings do not require a network connection.

## 3. Local Preferences

Bookmarks, recent component IDs, theme choices, accent settings, and reduced-motion preferences are stored locally with Android Preferences DataStore.

The DataStore preferences file is explicitly excluded from Android cloud backup and device-to-device transfer. Uninstalling the app or clearing its app data removes these preferences.

## 4. External Links

The app can open official Material documentation and project links in another installed application, such as a browser, only after you choose the corresponding action. Once another application opens a link, that application's and the destination website's privacy practices apply.

## 5. No Advertisements or Trackers

The Android app contains no advertisements and no third-party analytics or tracking SDKs.

## 6. Project Website

The documentation website does not include project-operated analytics or advertising trackers. The framework-free showcase can use browser local storage to remember visual preferences such as theme, color seed, radius, and widget display options. Those values remain in the browser unless you clear them.

The landing page requests public repository and release statistics from the GitHub API. The request does not include project credentials, and the page remains usable if the data cannot be loaded.

The website is hosted through GitHub Pages. GitHub or other providers used to deliver public statistics, linked fonts, and assets may process ordinary network request information under their own privacy policies.

## 7. Source Availability

The source code is publicly available for inspection on [GitHub](https://github.com/qtremors/material-design).

## 8. Changes to This Policy

This policy may be updated when project capabilities change. Material changes will be documented in the repository.
