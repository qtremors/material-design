Android Libraries and Versions

Reference for all library versions, Gradle catalog entries, dependency declarations, and plugins used by the Material Design Android project.

All version management lives in material-app/gradle/libs.versions.toml. Dependencies are declared in module build.gradle.kts files. For agent and harness use, see the Markdown version.

Compose & Material 3 Expressive

The checked-in version catalog is the project source of truth. Verify official release notes before changing any pinned alpha or adaptive dependency.

Library Version / Source
Compose BOM 2026.06.00
Material 3 Expressive 1.5.0-alpha23 (explicit, overrides BOM)
Material 3 Adaptive 1.2.0 (explicit)

Why explicit versions?

Material 3 Expressive (1.5.0-alpha23) and Adaptive (1.2.0) are pinned explicitly because the BOM may trail the alpha track. Always check Material3 releases before bumping.

Adding a New Library

  1. Add the version to [versions] in material-app/gradle/libs.versions.toml.
  2. Add the library entry to [libraries].
  3. Add the dependency to app/build.gradle.kts under the correct scope (implementation, testImplementation, etc.).
  4. Update both the HTML and Markdown dependency skills.
  5. Add a concise entry to the current section of the root CHANGELOG.md. Do not bump the app version unless explicitly requested.

Bumping a Version

  1. Update the version string in [versions].
  2. Sync the Gradle project.
  3. Verify no API breakage in the affected feature demos.
  4. Update both dependency skill files.
  5. Note it in the current section of the root CHANGELOG.md without changing the app version unless explicitly requested.
