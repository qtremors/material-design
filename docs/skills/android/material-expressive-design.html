Material 3 Expressive Design System

Guidelines and code patterns for Material 3 Expressive and Adaptive components, typography, motion, buttons, indicators, navigation, and toolbars.

This guide serves as a reference for designing and developing Android Jetpack Compose UI components with Material 3 Expressive APIs and project experiments.

Source-of-truth boundary: use the Android app catalog and the repository paths it exposes as the canonical, version-reviewed references. Any section explicitly labeled Project implementation is an experiment, not an official Material API.

[!IMPORTANT] When building or modifying expressive components, always cross-reference the official Google guidelines and API documentation:

  • Material Design 3 Guidelines (m3.material.io)
  • Android Compose Material 3 Release & API Documentation
  • Compose Adaptive Layouts Guide

1. Dynamic Typography (Variable Fonts)

Expressive typography utilizes Variable Fonts (e.g., google_sans_flex_variable.ttf) to morph text weights, widths, roundness, and grades dynamically.

Font Variation Settings Configuration

import androidx.compose.ui.text.font.FontVariation
import androidx.compose.ui.text.ExperimentalTextApi

@OptIn(ExperimentalTextApi::class)
data class FontAxes(
    val weight: Float,     // range: 100..1000
    val width: Float,      // range: 25..150
    val opsz: Float,       // range: 6..72 (Optical size)
    val grade: Float,      // range: -200..200 (Grade/contrast)
    val slant: Float,      // range: -10..0
    val roundness: Float   // range: 0..100 (ROND variation)
) {
    fun toVariationSettings() = FontVariation.Settings(
        FontVariation.weight(weight.toInt().coerceIn(1, 1000)),
        FontVariation.width(width.coerceIn(25f, 150f)),
        FontVariation.Setting("opsz", opsz.coerceIn(6f, 72f)),
        FontVariation.grade(grade.toInt().coerceIn(-200, 200)),
        FontVariation.slant(slant.coerceIn(-10f, 0f)),
        FontVariation.Setting("ROND", roundness.coerceIn(0f, 100f))
    )
}

3. Split Buttons

Split buttons partition a component into a primary action (leading) and a menu options trigger (trailing).

import androidx.compose.material3.SplitButtonLayout
import androidx.compose.material3.SplitButtonDefaults

@OptIn(ExperimentalMaterial3ExpressiveApi::class)
@Composable
fun ShareSplitButton(onShare: () -> Unit, onDropdownToggle: (Boolean) -> Unit, active: Boolean) {
    SplitButtonLayout(
        leadingButton = {
            SplitButtonDefaults.LeadingButton(onClick = onShare) {
                Icon(Icons.Default.Share, contentDescription = null)
                Spacer(Modifier.width(8.dp))
                Text("Share")
            }
        },
        trailingButton = {
            SplitButtonDefaults.TrailingButton(
                checked = active,
                onCheckedChange = onDropdownToggle
            ) {
                Icon(
                    imageVector = if (active) Icons.Default.KeyboardArrowUp else Icons.Default.KeyboardArrowDown,
                    contentDescription = null
                )
            }
        }
    )
}

Morphing & Touch Scaling Implementation

val isPressed by interactionSource.collectIsPressedAsState()
val animR by animateDpAsState(

Hold to Confirm Action

Tracks duration while held and executes a callback when progress reaches 1.0.

val holdAnim = remember { Animatable(0f) }
LaunchedEffect(isPressed) {
    if (isPressed) {
        val startTime = System.currentTimeMillis()
        while (true) {
            val elapsed = System.currentTimeMillis() - startTime
            val progress = (elapsed.toFloat() / holdDuration).coerceIn(0f, 1f)
            holdAnim.snapTo(progress)
            if (progress >= 1f) break
            delay(16)
        }
        if (isPressed) {
            onHoldComplete()
            holdAnim.snapTo(0f)
        }
    } else {
        holdAnim.animateTo(0f, spring(stiffness = Spring.StiffnessMedium))
    }
}

    )
}

7. Advanced Patterns Learned (Session 2026-06-29)

Scroll-Responsive Morphing Header Typography

Smoothly collapses display fonts to headline fonts during scroll offsets using standard linear interpolation (lerp). It dynamically alters the weight, width, and roundness (ROND) settings of Google Sans Flex variable font:

// Calculate fraction (0f fully expanded, 1f fully collapsed) from list scroll offset
val collapsedFraction = (scrollOffset.value.toFloat() / 250f).coerceIn(0f, 1f)

val titleWeight = lerp(950f, 700f, collapsedFraction)
val titleWidth = lerp(85f, 115f, collapsedFraction)
val titleRoundness = lerp(100f, 20f, collapsedFraction)

val customTypography = remember(titleWeight, titleWidth, titleRoundness) {
    VariableFontFactory.createTypography(
        GSFlexSettings(
            preset = GSFlexPreset.CUSTOM,
            display = FontAxes(weight = titleWeight, width = titleWidth, opsz = 32f, grade = 0f, slant = 0f, roundness = titleRoundness)
        )
    )
}

Custom canvas wavy circular progress (Project implementation)

Draws a smooth progress circle utilizing sine wave offsets for a wavy effect, animated using infinite transition phases:

@Composable
fun WavyCircularProgress(progress: Float, modifier: Modifier = Modifier) {
    val phase by rememberInfiniteTransition().animateFloat(
        initialValue = 0f,
        targetValue = 2f * Math.PI.toFloat(),
        animationSpec = infiniteRepeatable(tween(3000, easing = LinearEasing), RepeatMode.Restart)
    )
    Canvas(modifier = modifier) {
        val strokeWidth = 3.dp.toPx()
        val radius = (size.minDimension - strokeWidth) / 2
        val sweepAngle = progress * 360f
        val path = Path()
        val points = 180
        for (i in 0..points) {
            val angleRad = Math.toRadians((i.toFloat() / points * sweepAngle - 90f).toDouble()).toFloat()
            val r = radius + sin(angleRad * 8f + phase) * 1.5f.dp.toPx() // Wavelength freq 8, amplitude 1.5dp
            val px = (size.width / 2) + r * cos(angleRad)
            val py = (size.height / 2) + r * sin(angleRad)
            if (i == 0) path.moveTo(px, py) else path.lineTo(px, py)
        }
        drawPath(path = path, color = Color.Primary, style = Stroke(width = strokeWidth, cap = StrokeCap.Round))
    }
}

Expressive Hold Button with Outlining Progress

Tracks hold duration using MutableInteractionSource. When pressed, it scales down, morphs corner shapes via spring animations, and paints an animated border completion progress:

val isPressed by interactionSource.collectIsPressedAsState()
val scale by animateFloatAsState(if (isPressed) 0.94f else 1f)
val cornerRadius by animateDpAsState(if (isPressed) 12.dp else 24.dp)

Button(
    onClick = {},
    interactionSource = interactionSource,
    modifier = Modifier
        .graphicsLayer { scaleX = scale; scaleY = scale }
        .drawBehind {
            if (holdProgress.value > 0f) {
                drawRoundRect(
                    color = Color.White.copy(alpha = 0.8f),
                    size = this.size,
                    cornerRadius = CornerRadius(cornerRadius.toPx()),
                    style = Stroke(width = 3.dp.toPx())
                )
            }
        },
    shape = RoundedCornerShape(cornerRadius)
) {
    Text("Hold to Purchase")
}
