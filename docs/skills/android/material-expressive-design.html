Material 3 Expressive Design System

Guidelines and code patterns for Material 3 Expressive and Adaptive components, typography, motion, buttons, indicators, navigation, and toolbars.

This guide serves as a reference for designing and developing Android Jetpack Compose UI components with Material 3 Expressive APIs and project experiments. For agent and harness use, see the Markdown version.

Source-of-truth boundary: use the Android app catalog and the repository paths it exposes as the canonical, version-reviewed references. Any section explicitly labeled Project implementation is an experiment, not an official Material API.

[!IMPORTANT] When building or modifying expressive components, always cross-reference the official Google guidelines and API documentation:

  • Material Design 3 Guidelines (m3.material.io)
  • Android Compose Material 3 Release & API Documentation
  • Compose Adaptive Layouts Guide

1. Dynamic Typography (Variable Fonts)

Expressive typography utilizes Variable Fonts (e.g., google_sans_flex_variable.ttf) to morph text weights, widths, roundness, and grades dynamically.

Font Variation Settings Configuration

import androidx.compose.ui.text.font.FontVariation
import androidx.compose.ui.text.ExperimentalTextApi

@OptIn(ExperimentalTextApi::class)
data class FontAxes(
    val weight: Float,     // range: 100..1000
    val width: Float,      // range: 25..150
    val opsz: Float,       // range: 6..72 (Optical size)
    val grade: Float,      // range: -200..200 (Grade/contrast)
    val slant: Float,      // range: -10..0
    val roundness: Float   // range: 0..100 (ROND variation)
) {
    fun toVariationSettings() = FontVariation.Settings(
        FontVariation.weight(weight.toInt().coerceIn(1, 1000)),
        FontVariation.width(width.coerceIn(25f, 150f)),
        FontVariation.Setting("opsz", opsz.coerceIn(6f, 72f)),
        FontVariation.grade(grade.toInt().coerceIn(-200, 200)),
        FontVariation.slant(slant.coerceIn(-10f, 0f)),
        FontVariation.Setting("ROND", roundness.coerceIn(0f, 100f))
    )
}

2. Wavy Progress Indicators

Wavy progress indicators communicate determinate and indeterminate progress with expressive motion. Preserve progress semantics and provide the project's reduced-motion treatment.

Circular Wavy Progress Indicator

Used for download streams, circular timers, or loading status rings.

import androidx.compose.material3.CircularWavyProgressIndicator
import androidx.compose.material3.ExperimentalMaterial3ExpressiveApi

@OptIn(ExperimentalMaterial3ExpressiveApi::class)
@Composable
fun CircularWavyProgressDemo(progressState: Float) {
    CircularWavyProgressIndicator(
        progress = { progressState.coerceIn(0f, 1f) },
        modifier = Modifier.size(64.dp)
    )
}

Linear Wavy Progress Indicator

Used for progress loading blocks or music media seekbars.

import androidx.compose.material3.LinearWavyProgressIndicator

@OptIn(ExperimentalMaterial3ExpressiveApi::class)
@Composable
fun LinearWavyProgressDemo(progressState: Float) {
    LinearWavyProgressIndicator(
        progress = { progressState.coerceIn(0f, 1f) },
        modifier = Modifier.fillMaxWidth()
    )
}

3. Split Buttons

Split buttons partition a component into a primary action (leading) and a menu options trigger (trailing).

import androidx.compose.material3.SplitButtonLayout
import androidx.compose.material3.SplitButtonDefaults

@OptIn(ExperimentalMaterial3ExpressiveApi::class)
@Composable
fun ShareSplitButton(onShare: () -> Unit, onDropdownToggle: (Boolean) -> Unit, active: Boolean) {
    SplitButtonLayout(
        leadingButton = {
            SplitButtonDefaults.LeadingButton(onClick = onShare) {
                Icon(Icons.Default.Share, contentDescription = null)
                Spacer(Modifier.width(8.dp))
                Text("Share")
            }
        },
        trailingButton = {
            SplitButtonDefaults.TrailingButton(
                checked = active,
                onCheckedChange = onDropdownToggle
            ) {
                Icon(
                    imageVector = if (active) Icons.Default.KeyboardArrowUp else Icons.Default.KeyboardArrowDown,
                    contentDescription = if (active) "Hide sharing options" else "Show sharing options"
                )
            }
        }
    )
}

4. Project Button Morphing & Hold Confirmation

Project implementation. These experiments scale and morph buttons based on touch interaction. They must not be described as official APIs.

The maintained implementation is in samples/actions/.../ActionSamples.kt, while every shared spring and reduced-motion fallback comes from core/designsystem/.../ExpressiveMotion.kt. The snippets below explain the values; contributors should call the shared specifications instead of duplicating them.

Morphing & Touch Scaling Implementation

// Corner Morphing & Scale down on press
val isPressed by interactionSource.collectIsPressedAsState()
val animR by animateDpAsState(
    targetValue = if (isPressed) 12.dp else 24.dp,
    animationSpec = spring(dampingRatio = Spring.DampingRatioNoBouncy, stiffness = Spring.StiffnessMedium)
)
val scaleState by animateFloatAsState(
    targetValue = if (isPressed) 0.94f else 1.0f,
    animationSpec = spring(dampingRatio = Spring.DampingRatioMediumBouncy, stiffness = Spring.StiffnessLow)
)

Hold to Confirm Action

Tracks duration while held and executes a callback when progress reaches 1.0.

val holdAnim = remember { Animatable(0f) }
LaunchedEffect(isPressed) {
    if (isPressed) {
        val startTime = System.currentTimeMillis()
        while (true) {
            val elapsed = System.currentTimeMillis() - startTime
            val progress = (elapsed.toFloat() / holdDuration).coerceIn(0f, 1f)
            holdAnim.snapTo(progress)
            if (progress >= 1f) break
            delay(16)
        }
        if (isPressed) {
            onHoldComplete()
            holdAnim.snapTo(0f)
        }
    } else {
        holdAnim.animateTo(0f, spring(stiffness = Spring.StiffnessMedium))
    }
}

Dynamic Weight Segments

Adjusts item weights inside a Row on press/selection to dynamically nudge adjacent items.

val animatedWeight by animateFloatAsState(
    targetValue = when {
        isPressed -> option.weight * 1.4f
        isSelected -> option.weight * 1.2f
        else -> option.weight
    },
    animationSpec = spring(dampingRatio = Spring.DampingRatioLowBouncy, stiffness = Spring.StiffnessLow)
)

Project grouped-card shapes

Cards in a list that dynamically compute their shapes based on their position in the stack to blend together:

enum class GroupPosition {
    Top, Middle, Bottom, Single
}

fun getGroupShape(position: GroupPosition): RoundedCornerShape {
    return when (position) {
        GroupPosition.Top -> RoundedCornerShape(topStart = 24.dp, topEnd = 24.dp, bottomStart = 8.dp, bottomEnd = 8.dp)
        GroupPosition.Middle -> RoundedCornerShape(8.dp)
        GroupPosition.Bottom -> RoundedCornerShape(topStart = 8.dp, topEnd = 8.dp, bottomStart = 24.dp, bottomEnd = 24.dp)
        GroupPosition.Single -> RoundedCornerShape(24.dp)
    }
}

6. Floating Toolbars and Adaptive Navigation

Floating toolbars and the application navigation suite adapt to screen layouts.

Floating Toolbars

@OptIn(ExperimentalMaterial3ExpressiveApi::class)

        expanded = isExpanded,
        shape = RoundedCornerShape(100),
        colors = FloatingToolbarDefaults.standardFloatingToolbarColors(
            toolbarContainerColor = MaterialTheme.colorScheme.secondaryContainer
        )
    ) {
        // Toolbar actions
    }
}

Short Navigation Bar Item

Allows text labels to expand horizontally or vertically on item selection.

import androidx.compose.material3.ShortNavigationBarItem
import androidx.compose.material3.NavigationItemIconPosition

@OptIn(ExperimentalMaterial3ExpressiveApi::class)
@Composable
fun CustomShortNavItem(selected: Boolean, onSelect: () -> Unit, label: String, icon: ImageVector) {
    ShortNavigationBarItem(
        selected = selected,
        onClick = onSelect,
        icon = { Icon(icon, contentDescription = null) },
        label = {
            AnimatedVisibility(visible = selected) {
                Text(text = label, fontWeight = FontWeight.ExtraBold)
            }
        },
        iconPosition = NavigationItemIconPosition.Start
    )
}
