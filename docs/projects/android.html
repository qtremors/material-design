Material Design for Android

A searchable Kotlin and Jetpack Compose component gallery whose modular source is the working Material 3 reference for people and coding agents.

android Version 2.0.0construction Work in progress

Purpose

Make working UI easy to find and reuse

The app is the visual truth and the repository is the code truth. Search an official component name or alias, experience its real states and variants, inspect its API status, then copy the repository-relative path to the state-hoisted implementation. It has no lessons, accounts, simulated installs, or placeholder components.
