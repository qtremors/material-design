Material Design for Android

A searchable Kotlin and Jetpack Compose component gallery whose modular source is the working Material 3 reference for people and coding agents.

android Version 2.0.3verified Active reference

Purpose

Make complete Material products possible to understand and build

The app is the visual and behavioral truth, the catalog explains the design decisions, and the repository is the implementation truth. Search an official component name or alias, experience real states, read when and when not to use it, verify accessibility and adaptation, inspect API status, then copy the repository-relative path to the state-hoisted implementation. It has no accounts, simulated installs, or placeholder components.
