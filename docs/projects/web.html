Completion

Definition of web parity

  • UI and UX intent matches the accepted Android reference.
  • Platform-specific differences are intentional and documented.
  • All applicable component states are implemented.
  • Compact, medium, expanded, compact-height, zoomed, and resizable layouts remain usable.
  • Keyboard, touch, screen-reader semantics, focus, contrast, and reduced motion are verified.
  • Public data fails gracefully and no client credentials are used.
  • Parity status, site map, HTML skills, Markdown skills, and changelog are current.
