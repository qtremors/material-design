The original responsive 1.5.0 website remains the current browser component implementation. It is preserved as older work and does not receive parity updates. Future Material Web will provide an independent counterpart to stabilized Android references.

Implementation

Independent by design

Semantic structure

Native HTML and correct accessible roles define the interaction before visual polish.

Web-owned tokens

Color, type, shape, spacing, elevation, and motion use browser-specific custom properties.

Responsive layout

Compact, medium, expanded, and fluid intermediate widths are verified independently.

Input coverage

Keyboard, pointer, touch, assistive technology, zoom, and reduced motion are first-class paths.

Completion

Definition of web parity

  • UI/UX intent matches the accepted Android reference.
  • Platform-specific differences are intentional and documented.
  • All applicable component states are implemented.
  • Compact, medium, expanded, and resizable layouts remain usable.
  • Keyboard, screen-reader semantics, zoom, and reduced motion are verified.
  • Parity status, documentation, and changelog are current.
